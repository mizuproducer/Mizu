What to do

    Doses are estimates. Add about half, circulate, retest, then add the rest. Always add chemicals to water, never water to chemicals.

    Connect your tester

    Pair with a Mizu tester nearby. Bluetooth reaches roughly 10–100 m depending on walls and the tester's antenna. Use Remote for farther away.

    Set up long-distance mode (Wi-Fi)

    Send your Wi-Fi details to the tester once. It then sends readings over the internet, so you can check them from anywhere in Remote mode.

    See readings from anywhere with internet. The tester must be on Wi-Fi (set it up once over Bluetooth). Its ID is printed on the device and shown after pairing.

    Server settings

    The default is a free public server, so anyone who knows your tester ID can see its readings. Use your own server for privacy.

    No tester yet? Run a simulated one, or type in numbers from a test strip or drop kit.
